Spatialized Video

This sample plays four 2D videos back to back in a quad media layer, restarting after the last one. When Spatialize is checked, each layer is created with spatialize: true, which asks the browser to show the video in stereo using depth estimated from its frames. Changing the setting takes effect at the next video. Pull the trigger to skip to the next video. Back

spatialize is only a hint: the browser may ignore it, and the page can't tell whether a video is being spatialized. Because it can only be set when a layer is created, the sample creates a new media layer for each video, which also lets the layer match the video's aspect ratio.
