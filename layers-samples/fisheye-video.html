Fisheye Video

This sample plays a 180-degree video, captured through a fisheye lens, in a fisheye media layer. The browser maps the image onto a hemisphere around the viewer using the lens description that's passed to createFisheyeLayer(), so the page doesn't have to convert the video to an equirectangular projection. When the session starts, the layer's visibleFieldOfView opens up from the center. Pull the trigger to pause or resume the video. Back

The lens description comes from the calibration stored in the video's metadata, which uses the omnidirectional lens model. The video stores a separate view for each eye, so the layer is created with the stereo layout. If the browser can't show the two views separately, both eyes see the primary view.
